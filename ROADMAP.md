# Rapfa — Product & Engineering Roadmap

## Public source milestone: v0.1.0
- [x] Separate public/ from server source; disallow unknown URL paths.
- [x] Reproducible three-file build and GitHub Actions API integration tests.
- [x] Repair player visibility, CSS selectors and external source labels.
- [x] Real Chromium E2E with synthetic API interception and a mobile viewport.
- [ ] Make API base URL configurable for local/full-stack and static-host modes.
- [ ] Create a browser screenshot/visual-regression baseline.
- [ ] Add API rate limits, optional caching and clearer upstream failure telemetry.
- [ ] Improve accessibility of modal focus control and screen-reader announcements.
- [ ] Test with real upstream providers under their acceptable-use rules.
- [ ] Versioned deployments with rollback, incident diagnostics and uptime monitoring.

### Release policy
Do not attach or redistribute copyrighted audio files. Source releases should be tagged after CI succeeds; upstream availability and external embeds cannot be guaranteed.
